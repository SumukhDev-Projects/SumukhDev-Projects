# Hi, I'm Sumukh

I'm a data analyst at the University of Illinois Extension in Chicago. I build the reporting pipelines and dashboards behind public-health nutrition programs, and I work on AI agents and how to evaluate them. I hold an M.S. in Engineering Management (Data Analytics) from UIUC and co-founded Enthara Research.

## What I'm working on

- **Federal program reporting.** SQL pipelines and Tableau dashboards for Illinois SNAP-Ed and EFNEP reporting to IDHS and USDA.
- **Statewide listening-session analysis.** A Python pipeline with human-reviewed LLM coding for a report to the Illinois General Assembly.
- **Mercury and Lunar at Enthara Research.** A memory system for AI agents and a research preview on reading human signals. See [mercury.enthara.ai](https://mercury.enthara.ai).
